# what is 'traffic-intelligence-system' ?

the projects 'Traffic Intelligence System' (shorten to TIS) aims to keep track on public and private transport, in order to improve the public transport, lessen accidents from happening and infom drivers about traffic problems.

This project is my final education project, it is not connected to any real company at all, so any connection to real compaines in the future is not intencinale.
